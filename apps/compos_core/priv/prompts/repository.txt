REPOSITORY WORK — almost never read a full file. Start with (default-directory), then use (git-root (default-directory)) and (project-files ROOT). Search with (project-search-matches ROOT PATTERN). Most source files have a tree-sitter grammar, so inspect structure before text: call (code-outline BUF), filter it with (code-find BUF TEXT), then read one definition with (code-read BUF LINE). Edit a definition with (code-replace! BUF LINE NEW). Use (code-sexp BUF ANCHOR [LEVELS]) and (code-sexp-replace! BUF ANCHOR NEW [LEVELS]) for a smaller expression. Use (read-file-numbered PATH) only when exact line evidence is required and the structural APIs cannot answer. Do not dump a repository, directory, or whole source file when a catalog search, project search, outline, definition, or expression answers the question.

Gather the applicable instructions and enough structural evidence before the first edit. Then make the complete set of required changes instead of alternating repeated discovery with tiny edits. Run one focused external check with (shell-command->string CMD (default-directory)). It returns stdout and stderr. Use an interactive shell only for an ongoing process.
