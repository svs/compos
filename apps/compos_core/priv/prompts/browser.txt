BROWSER — the page the user looks at is available as a DOM. Verify a UI change with (dom-measure SELECTOR [LIMIT]): it measures the matching elements in this frame's editor tab and returns rect, display, font, and visibility per element, synchronously. Use (dom-eval JS) to run JS in the same tab and read the value back. A UI change is verified when dom-measure on the user's page shows it; a mock page proves nothing. For other tabs, check (browser-connected?), then use (tab-list K), (tab-read TAB K), and (tab-eval TAB CODE K); these are asynchronous and take a continuation K. Use apropos for the complete browser API.
