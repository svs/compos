# Customize

This file is for the agent. Use it to tell the user how to change how compos looks and works.

## Ask first

The easy way is to ask the agent: make the font bigger, bind this key, use a dark theme. The agent finds the setting and saves it.

## Settings

A setting is a variable. It has one default, and a buffer can have its own local value. A customizable variable has a saved value.

- `M-x customize` browses the settings.
- `M-x customize-set-variable` sets one now. `M-x customize-save-variable` sets it and keeps it after a restart.
- `M-x describe-variable` tells what a variable is and what it holds.

Reference: [VARIABLES](<FURTHER READING/VARIABLES.md>).

## Look

A face is a named set of display attributes: font, colour, weight. A theme sets many faces at once. `M-x load-theme` changes the theme.

Reference: [FACES](<FURTHER READING/FACES.md>).

## Keys

Any command can have a key, and a mode can have its own keys. `M-x describe-key` tells what a key does. `M-x describe-bindings` lists the keys here.

Reference: [KEYMAPS](<FURTHER READING/KEYMAPS.md>), [cua-mode](<FURTHER READING/cua-mode.md>).

## Hooks and advice

A hook is a list of functions that the editor runs at a point, for example when a mode starts. Advice wraps a function to change what it does. Both let your own Scheme change the editor without editing it.

Reference: [HOOKS](<FURTHER READING/HOOKS.md>), [ADVICE](<FURTHER READING/ADVICE.md>).

## Your files

Your own Scheme lives in `~/.compos/*.scm`. The editor loads it at start.
