# Apps

This file is for the agent. Use it to tell the user what an app is in compos and how to get a new one.

## What an app is

An app is a list with one row per thing, a detail buffer for each row, and the same actions on both. One command opens it. Because every app uses the same list mode, the same keys mark, filter and act everywhere.

compos often brings an outside service into the editor as an app. Then its data is in a buffer, and an agent can read it there without a chain of tool calls.

Reference: [INTRODUCTION](<FURTHER READING/INTRODUCTION.md>), [LISTS](<FURTHER READING/LISTS.md>).

## Apps you have now

- **Buffers**: `M-x ibuffer`.
- **Files**: `M-x dired`.
- **Chats**: `M-x chat-list`.
- **Todos**: `M-x todo`.
- **Web pages**: `M-x browse` reads a page as text in a buffer.
- **Messages**: `M-x view-messages`.

## Getting a new app

Ask the agent. For example: make me a Sentry app. Put the API key in your secrets, and the agent writes the app in Scheme while the editor runs. It can add an action on a row, for example a button that asks an agent to fix an issue.
