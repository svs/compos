# Learn Compos

The canonical learn-by-doing tutorial is the tutorial package's
[`scheme/packages/tutorial/COMPOS.md`](../scheme/packages/tutorial/COMPOS.md).
In the tutorial, the lesson pane visits that file: edit a lesson there and
press `C-x C-s` to change the bundled tutorial. The slide follows as you type.

Inside Compos, choose **Set up AI** on the Welcome page if you want a chat or
agent. The [AI starter guide](../apps/compos_core/priv/tutorials/START-WITH-AI.md)
walks from a working connection to chats, file context, separate tasks, and
permissions. Press `C-h t` or choose **Start the tutorial** on the Welcome
page.

The tutorial is a continuous learn-by-doing introduction to the Compos
philosophy, Emacs interaction model, buffers and windows, uniform lists and
browsing, groups, companion agents, persistence, and live Scheme extension.
