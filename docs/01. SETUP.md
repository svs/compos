# Set up compos

Do the following steps, or ask your agent to do them: "Set up compos for me. Follow SETUP.md in <REPO-URL>." compos ships as one binary, so there is nothing to build. To build from source instead, see [INSTALL.md](../INSTALL.md).

Do the steps in order. Each step has a check. If a check fails, stop and fix it before you continue. Type API keys only into `⌥x setup`; do not paste them anywhere else.

### 1. Get the binary

Find your platform with `uname -sm`. Each release on <REPO-URL>/releases has two binaries:

- `compos-VERSION-macos_arm`: macOS on Apple silicon (`Darwin arm64`).
- `compos-VERSION-linux`: Linux on x86_64.

Other platforms have no binary yet. Download the binary of the latest release into `~/.local/bin/compos` and make it executable:

```sh
chmod +x ~/.local/bin/compos
xattr -d com.apple.quarantine ~/.local/bin/compos   # macOS only
```

The first run unpacks itself once and is slower.

Check: `~/.local/bin/compos --version` answers.

### 2. Run it

```sh
~/.local/bin/compos &   # serves http://localhost:4004
```

Open the editor in Chrome: `open -na "Google Chrome" --args --app=http://localhost:4004`. Any other browser at that address also works.

Check: you see the editor at `http://localhost:4004`. The state lives in `~/.compos`.

### 3. Connect your agent to the editor

The editor is an MCP server. For Claude Code:

```sh
claude mcp add --scope user compos -- <MCP-SHIM-PATH>
```

Restart the agent session.

Check: the `eval-scheme` tool of the `compos` server answers `(setup-report)`.

### 4. Configure

Run `⌥x setup` in the editor. It sets the chat connector, secret storage, model presets and the decision model. An agent can do the same steps through `eval-scheme`; see [INSTALL.md](../INSTALL.md) from step 4.

compos needs only inference. The decision model and embeddings are optional: without them, `apropos` uses plain word matching, which is enough. Set them up when they are easy to get, and skip them when they are not.

### 5. Fast model when JEV is not there

A fresh install does not have JEV. Use the fast model of the agent you already have: Claude Code's Haiku, or Codex's fast model. In `⌥x setup`, put it in the `fast` and `summarize` presets ([INSTALL.md](../INSTALL.md) step 6), remove `jev` from `decide-backends`, and set `command-palette-decide-backend` to `model`.

Check: `(llm-model-for 'fast)` names that model, and `decide-backends` does not name `jev`.

### 6. Chrome extension: do not skip

The extension lets compos read and act in your own Chrome, with your logins. compos copies it to `~/.compos/chrome-extension` at every start.

If that folder is not there, the running compos is older than this step. Quit compos and start it again, then look again. When compos runs from a source checkout, start it from the repository root.

1. Open `chrome://extensions`.
2. Turn on **Developer mode**, top right.
3. Click **Load unpacked** and choose `~/.compos/chrome-extension`. In the file picker, Cmd-Shift-G lets you type a path.

Check: `(browser-connected?)` answers `#t`. If it does not, stay on this step. Details: [CHROME_EXTENSION.md](FURTHER READING/CHROME_EXTENSION.md).

### 7. Make Caps Lock a Ctrl key

compos uses Emacs keys, and most of them start with Ctrl. Caps Lock is easier to reach, so make it a Ctrl key.

- **macOS:** open System Settings > Keyboard > Keyboard Shortcuts > Modifier Keys. Set **Caps Lock key** to **Control**. Do this for each keyboard in the list at the top.
- **Linux, GNOME:** `gsettings set org.gnome.desktop.input-sources xkb-options "['ctrl:nocaps']"`
- **Linux, other desktops:** `setxkbmap -option ctrl:nocaps`. Add it to your session startup so that it stays after a restart.

The docs write keys with Mac symbols: ⌃ is Ctrl (now Caps Lock), ⌥ is Option, ⌘ is Cmd and ⇧ is Shift. On Linux, ⌥ is Alt and ⌘ is Super.

Check: in the editor, hold Caps Lock and type `x` then `f`. The prompt to open a file appears. Press Caps Lock + `g` to close it.
