Groups and switching

Context management is one of the main goals of ai-max. A group is one working context: the buffers that belong together, their window arrangement, their chat, and their metadata. The buffer switcher moves you between contexts.

The model

A group is nothing but a shared buffer-local: every member carries 'group "name". Membership is stored nowhere else. A killed buffer leaves the set; (group-buffers g) derives the set on demand.

The group's durable state lives on its chat buffer (*chat:NAME*), as identity locals:

localholds
'group-metaone sentence of metadata — what the group is for
'group-layoutthe saved window arrangement, as one opaque value
'group-noisethe companion policy: off, quiet, or loud

Identity locals survive reset, restart, and save. The desktop file keeps them; a daemon restart brings every group back whole.

The frame remembers which group you stand in ('current-group, a frame-local). A detour through an ungrouped buffer — *scratch*, help — does not lose the context. The frame group changes only when you switch groups.

The switcher: C-x b

Two gestures, never mixed. RET switches a BUFFER: one window changes, nothing else moves. C-RET switches a CONTEXT: the picked buffer's group comes up, layout and all. The same rule Emacs keeps between C-x b and tab-bar / perspective switching.

The pool is the recency stream — history first: the buffer you just left is the default, so RET toggles like the Emacs buffer ring. Groups have no rows of their own; every buffer row IS a group row.

Each row shows four columns: the mode, the group, the project, and the file. What you type matches the buffer name and the first three columns. So mail finds the mail group's buffers, elixir finds the Elixir buffers, and a project name finds that project's buffers.

you presswhat happens
RETthe buffer switches in this window — always, any group. The frame keeps its context.
C-RETyou enter the buffer's context: its group's layout comes up with point in the buffer
C-RET on a project file with no groupthe project BECOMES a group — its open buffers join, named by the root — and you enter it
RET on a name that matches nothingfounds a group with that name from the current windows

TAB locks the switcher to a group: with an input that names exactly one group, the pool narrows to that group's buffers, with the group's card on top. C-g quits and restores what the preview displaced.

The prompt renders as a centered palette. Every prompt with candidates does — M-x, find-file, the switcher. A line input keeps the bottom bar. Cmd-k opens M-x.

Layouts: captured and restored

A group carries its window arrangement. The snapshot is the frame's window tree — splits, ratios, buffers, scroll, point — stored as one value on the group chat.

When a snapshot is taken:

  • when you open the switcher from inside a group;
  • when you switch away from a group.

A snapshot is taken only while the group is on screen. A full-frame scratch detour does not overwrite the real arrangement. A stale snapshot that shows none of the group heals itself: the switch builds the default arrangement and saves it over the bad one.

When a group has no snapshot, it still arrives arranged: the most recent work buffer on the left, and on the right the group chat (noise loud) or the next work buffer. One member alone fills the frame.

The groups board: C-x G

One row per group: name, member count, noise, the most recent members, and the metadata.

Files you open from inside a group join it. Pop a buffer out with group-remove, or move it with C-c g.

Companion noise

Each group sets how loud its chat companion is. The setting persists with the group.

levelmeaning
offno companion window in the default layout
quietthe default — companion works out of view
loudthe chat keeps its own column in the default layout

Persistence

Everything survives a daemon restart. File buffers reopen from disk and their 'group tag is laid back on top. Non-file buffers restore with content. The group's chat carries the metadata, the layout, and the noise policy through desktop.etf. Derived state — a diff's rendered blocks — is declared with 'desktop-skip-locals and rebuilt from its source instead of saved.

Internals: the groups section of apps/aimax_core/priv/editor.scm. The layout primitives are window-tree / window-tree-set!. The switcher is switch-to-buffer in the same file.
