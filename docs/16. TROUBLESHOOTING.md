# Troubleshooting

This file is for the agent. Use it to help the user when something does not work.

## Ask the editor

- `M-x describe-key`: what does this key do?
- `M-x describe-mode`: what mode is this buffer in, and what are its keys?
- `M-x describe-bindings`: every key here.
- `M-x describe-variable`: what is this setting?
- `M-x apropos`: find a command or function by words.
- `M-x view-messages`: the editor's messages and errors.

## A chat does not answer

`M-x chat-abort` stops the turn that runs now. `C-c b` (`M-x llm-configure`) shows the connector and the model. See [1. SETUP](<1. SETUP.md>) to connect again.

## Ask the agent

Tell the agent what you did and what you saw. It can read the buffers, the messages and the code, and fix the problem while the editor runs.
