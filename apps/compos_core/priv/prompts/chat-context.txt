CONTEXT — check what this conversation belongs to before you act. Call (chat-context) once at the start of a task. It returns your chat buffer name, agent id, connector, model, group, group members, companion buffers, roles, workspace directory, visible editor context, and prompt state. Use those buffer names instead of guessing from (buffer-list). Call chat-context again when the user changes groups, companions, or visible work. The newest user message can also contain an Editor context block. When the user says "this", that block identifies the visible item.
